Cobblemon Trials Edition 
=======

Cobblemon Trials Edition is a mod for Cobblemon that adds a set of highly configurable Cobblemon Trial Spawners to replace generated Mob Spawners, Trial Spawners, or Block in Structures or Features that you want to configure. By Default there is a list of structures and blocks listed below that the mod will replace. Any of these can be modified with a Datapack and new structures can be added the same way. The Spawners function almost exactly like regular Trial Spawners so players and modpack makers do not have to learn any new mechanics, but they can also be customized with a Wave mode, for any makers looking to provide a challenge or custom scenario for their players.

The mod also includes the ability to edit Cobblemon Trial Spawners directly with an in game UI, so people who want to create their own structures or adventure maps can modify the spawners however they like. Checkout the [Wiki](https://github.com/Lemenok/Cobblemon-Trials-Edition/wiki) for more information on the full customization and functionality of the Cobblemon Trial Spawners.

Default Features included by installing this mod
=======
- Custom Cobblemon Trial Spawner configurations that will replace the Mob Spawners, Trial Spawners, and Skulk Shriekers for the following Structures/Features:
  - Minecraft Monster Rooms
  - Minecraft Abandoned Mineshafts
  - Minecraft Nether Fortresses
  - Minecraft Bastion Remnants
  - Minecraft Trial Chambers
  - Minecraft Strongholds
  - Minecraft Ancient Cities
  - Minecraft Sculk Patches
  - Cobblemon Shipwreck Coves
- Default Spawner/Trial Spawner replacement for all Vanilla mobs in any other Structures or Features.
- A new Trial Potion, allowing access to the Trial Omen effect while playing in Peaceful mode.
- A custom recipe for Create to work with the lack of Blaze Spawners.
- Peaceful mode Spawning
- Many Configuration Options including the following:
  - Enable or Disable if Pokemon are Uncatchable
  - Enable or Disable if Pokemon must be Defeated in Battle
  - Enable or Disable if Pokemon are Aggressive if Fight or Flight is installed.
  - Percentage based Spawner Replacement
  - Percentage based Alpha Pokemon Spawn chance.
  - Enable or Disable Automatic Level adjustment for the spawners and if they are based on Average or Median of a players party.
  - A Configurable timeout for Spawned Pokemon.

Creator Features
=======
- A UI to Configure Cobblemon Trial Spawners
  - Spawner Settings, including Spawn ticks, Cooldowns, Wave Mode, and more.
  - Loot Tables for normal and Ominous modes with Weights and autocomplete.
  - Weighted spawns for both normal and ominous modes, with weights and completely customizable pokemon traits, EVs, IVs, Natures, etc.
  - Mega Showdown support for Mega and GMax Pokemon.
- 10 Textures to use in your builds to fit the Theme you are going for in your structure or adventure map.
- A Mysterious Tablet which enables quick testing and copy pasting of spawner settings. 
- Datapack Support
  - Almost every aspect of the Spawner is configurable. From Number of Pokemon, Spawn Ticks, Spawner Cooldowns, etc.
  - Can replace Spawner based on Structure, Spawner Type, and Entity in Spawner
  - Completely configurable loot tables for Spawners, allowing multiple loot tables if desired or to Inherit the original Loot Tables from the Trial Spawners they replace.
